# VIKING GPU 監視ページ（メンバー用）

B300（Slurm）と RTX PRO 6000 の使用状況を、1 分ごとに更新されるページで見られます。
データは 1 台の Mac がまとめて取ってきて、このリポジトリの `status` ブランチに置いています。
見る人はクラスタに ssh する必要がありません。

**このリポジトリは非公開のままにしてください。** ジョブ名やメンバーの名前が載っています。

## 見かた

ターミナル（Windows は Git Bash）で、最初に一度だけ取ってきます。

```bash
git clone -b status --depth 1 https://github.com/<owner>/viking-gpu-status.git ~/viking-gpu-status
```

見るときは、これを打ちます。ブラウザでページが開き、1 分ごとに新しくなります。止めるときは `Ctrl+C` です。

```bash
bash ~/viking-gpu-status/gpu_view.sh
```

- clone のときに GitHub のサインインを聞かれたら、自分のアカウントで入ってください（招待を受けている必要があります）。
- 画面の上に赤い「更新停止」が出たら、配信している Mac が止まっています。配信している人に知らせてください。

## ページの見かた

- **オレンジの区画が B300**（Slurm、GPU 4 基・CPU 64 コア）、**水色の区画が RTX PRO 6000**（チームの VM、Slurm なし）です。
- カードの左上の札（`B300` / `RTX`）で、どちらの機械のジョブかが分かります。
- 残り時間が赤く点滅しているジョブは、上限時間の 85% を超えています。
- CPU は割り当てられたコア数で、実際の負荷ではありません。
